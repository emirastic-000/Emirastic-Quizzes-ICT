🎯 WORKFLOW
─────────────────────────────────────────────────────────────

1. USER NAVIGATION
   │
   ├─ Click 🛠️ "Build Quiz" button
   │
   └─ → Directed to /builder page

2. QUESTIONS TAB
   │
   ├─ View list of custom questions
   ├─ Click "+ Create New Question"
   ├─ Fill form with validation
   ├─ Click "Create Question"
   │
   └─ → Question saved to database

3. QUIZZES TAB
   │
   ├─ View list of custom quizzes
   ├─ Click "+ Create New Quiz"
   ├─ Select questions to include
   ├─ Configure settings
   ├─ Click "Create Quiz"
   │
   └─ → Quiz appears on Dashboard

4. TAKE QUIZ
   │
   ├─ Go to Dashboard
   ├─ Find custom quiz
   ├─ Click [Take Quiz]
   ├─ Answer questions
   ├─ Submit
   │
   └─ → Results stored & tracked

─────────────────────────────────────────────────────────────

🚀 QUICK START (5 MINUTES)
─────────────────────────────────────────────────────────────

Step 1: Go to Builder
  → Click 🛠️ "Build Quiz" in navbar

Step 2: Create Question
  → Tab: "📝 Questions"
  → Button: "+ Create New Question"
  → Fill form, click "Create Question"

Step 3: Create Quiz
  → Tab: "📋 My Quizzes"
  → Button: "+ Create New Quiz"
  → Select question, click "Create Quiz"

Step 4: Take Quiz
  → Go to Dashboard
  → Find your quiz
  → Click [Take Quiz]

📋 FORM VALIDATION
─────────────────────────────────────────────────────────────

Question Form Requires:
  ✓ Question text (not empty)
  ✓ Category selection
  ✓ At least 2 options
  ✓ Exactly 1 correct answer
  ✓ All options have text
  ✓ Explanation provided

Quiz Form Requires:
  ✓ Title (not empty)
  ✓ At least 1 question selected
  ✓ Questions exist in database
